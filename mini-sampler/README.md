# Mini Sampler — Compact Edition

Version légère et portable du drum sampler PULSE.

Parfait pour une utilisation mobile et rapide.

## Caractéristiques

- **4 pads** avec feedback LED
- **8 steps** séquenceur
- **Mixer** : volume, Mute par piste
- **Effets** : Reverb, Filter low-pass
- **Import samples** : fichiers audio locaux
- Sons procéduraux intégrés (Kick, Snare, Hi-Hat, Clap)
- Interface compacte et responsive
- BPM ajustable

## Raccourcis

| Touche | Action |
|--------|--------|
| `1`–`4` | Jouer les pads |
| `Espace` | Play / Pause |

## Test local

```bash
cd mini-sampler
python -m http.server 8080
```
